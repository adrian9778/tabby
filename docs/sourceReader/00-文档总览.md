### 15-glossary.md — 术语表

| 术语 | 说明 |
|------|------|
| Agent | tabby-agent, IDE 中运行的 TypeScript 进程 |
| Service Locator | ee/tabby-schema 中的 ServiceLocator trait, 统一管理所有内部服务 |
| Tantivy | Rust 全文搜索引擎, Tabby 用于代码索引与结构化文档检索 |
| tree-sitter | C/Rust 语法解析库, Tabby 用于 AST 级别的代码分析 |
| Postprocessor | IDE 端 completion 结果的后处理管道 (20+ rules) |
| Service Locator Pattern | EE 中管理所有业务服务的接口模式 |
| Relay Pagination | ee/tabby-schema/juniper/relay/ 中的分页规范 |
| Access Policy | EE RBAC 核心概念, 控制用户/用户组对资源的访问权限 |
| Ingestion | 自定义文档通过 crawler 采集、解析、索引到 Tantivy 的完整流程 |
| WAL Mode | SQLite Write-Ahead Logging, tabby-db 默认开启以提升并发读取 |
